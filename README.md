# Quality WorX Knowledge Base

Separat kunskapsbas för Quality WorX Apps. Denna mapp är **inte** en del av plattformsrepot `qualityworx-platform`.

## Syfte

- bevara generella produktoriginal
- samla bearbetad produktkunskap
- dokumentera produkter och källspår
- stödja digitalisering av KvalitetsDokuments Word- och PDF-produkter

Vi digitaliserar inte Word. Vi digitaliserar kunskapen.

## Struktur

```text
quality-worx-knowledge-base/
├── README.md
├── originals/
├── processed/
├── products/
├── registry/
└── reports/
```

## Regler

- Originalfiler i `originals/` ändras inte.
- Kundspecifikt material publiceras inte automatiskt här.
- Licensierade standarder behandlas restriktivt.
- Appkod hör hemma i `qualityworx-platform`, inte här.
- Osäkert material placeras i `quality-worx-inbox`.
