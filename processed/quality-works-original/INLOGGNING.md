# Inloggning – Quality Works

## För alla användare
1. Klicka på Quality Works ikonen.
2. Välj din användare från listan.
3. Skriv in ditt lösenord.
4. Tryck ENTER eller Logga in.

**Glömt lösenord?**
Klicka på "Glömt lösenordet?" – du får ett mejl till din registrerade e-post.

## Admin vs Vanlig användare
- **Admin**: Full åtkomst till alla funktioner, kan godkänna dokument, skapa användare.
- **Vanlig användare**: Kan läsa dokument, lämna avvikelser/förslag, delta i enkäter. Eventuellt utökad behörighet via Konto och lösenord.

**Tips**: Byt ADMIN lösenord direkt för säkerhet.
