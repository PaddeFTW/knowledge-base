## Color Palette
| Token | HEX | RGB | Usage |
|-------|-----|-----|-------|
| --bg-primary | #050508 | rgb(5, 5, 8) | Main background |
| --bg-secondary | #11131A | rgb(17, 19, 26) | Cards, panels |
| --bg-tertiary | #1A1C26 | rgb(26, 28, 38) | Modals |
| --text-primary | #FFFFFF | rgb(255, 255, 255) | Headings |
| --text-secondary | #A8B0C0 | rgb(168, 176, 192) | Body |
| --accent-primary | #00E5FF | rgb(0, 229, 255) | Primary CTA |
| --laser | #00B4FF | rgb(0, 180, 255) | Signature glow |

**Laser Glow**: `box-shadow: 0 0 8px #00E5FF, 0 0 20px #00B4FF, 0 0 40px rgba(0,180,255,0.35);`

**Border Radius**: 12px (runda, futuristiska)

**Typography**: Space Grotesk (headings), Inter (body)

**Buttons**: Stark laser glow, rundade (12px), hover scale + glow

**Användning i Next.js + Tailwind + shadcn/ui**:
- Definiera CSS variables i globals.css
- Använd i komponenter för dark mode med laser accents
- Perfekt för ISO/SaaS dashboard med modern känsla
