# Personalenkät – Quality Works

**Syfte**: Anonym medarbetarundersökning för trivsel, delaktighet, information, arbetsledning, utvecklingsmöjligheter, mobbning, förbättringsarbete och helhetsbedömning.

## Admin – Inställning (Meny Admin → Enkät)
1. **Flikar**: Trivsel, Delaktighet, Information, Arbetsledning, Utvecklingsmöjlighet, Mobbing, Förbättringsarbete, Helhetsbedömning.
2. Redigera flikar: Lägg till/ta bort/ändra ordning.
3. Frågor per flik: Lägg till, redigera, ta bort (1-6 skala).
4. **Tidsperiod**: Från/Till + Välj mottagare + Information till mottagare.
5. **Börja om**: Nollställ resultat för ny omgång.

## Användare – Besvara enkäten
- Startsida → Information → Befattning → **Personalenkät**.
- Logga in med eget konto (anonyma svar).
- Välj nivå 1–6 per fråga → **Nästa** / **Föregående**.
- Sista fliken → **Skicka** (anonymt).

## Admin – Resultat
- **Inkomna svar**: Per fråga (antal, poäng, %).
- **Sammanställning**: Per flik (snitt %).
- **Kommentarer**: Alla fria kommentarer.

**Tips**: Använd för att identifiera förbättringsområden och följa upp över tid.
